# Two Sum

## Объяснение решения

Даны массив `arr` и число `k`. Нужно найти **индексы двух элементов**, сумма которых равна `k`.

Реализованы **два способа**:

### Способ 1: Вложенные циклы (O(n²))

Для каждого `i` перебираем все `j > i` и проверяем `arr[i] + arr[j] == k`.

**Почему работает:** перебираем все возможные пары — гарантированно находим нужную.

### Способ 2: Словарь (O(n))

Идём по массиву и для каждого `arr[i]` проверяем: есть ли в словаре `k - arr[i]`?
- Если есть — нашли пару, возвращаем `(d[elem], i)`.
- Если нет — кладём `arr[i]` в словарь (ключ = значение, значение = индекс).

**Почему работает:** словарь хранит **уже просмотренные** числа. Когда встречаем `arr[i]`, проверяем, есть ли среди них дополнение до `k`. Если да — пара найдена.

## Оценка сложности

| Способ | Время | Память |
|--------|-------|--------|
| Вложенные циклы | O(n²) | O(1) |
| Словарь | O(n) | O(n) |

**Вложенные циклы:** n итераций внешнего × n итераций внутреннего = O(n²).

**Словарь:** n итераций, каждая — O(1) проверка в словаре = O(n).

## Визуализация работы

**Пример:** `arr = [1, 3, 4, 10]`, `k = 7`

### Способ 2 (словарь):

| i | arr[i] | elem = k - arr[i] | Словарь d | Действие |
|---|--------|-------------------|-----------|----------|
| 0 | 1 | 6 | {} | 6 нет → `d[1] = 0` |
| 1 | 3 | 4 | {1:0} | 4 нет → `d[3] = 1` |
| 2 | 4 | 3 | {1:0, 3:1} | 3 есть! → `return (1, 2)` ✅ |

**Результат:** `(1, 2)` — индексы элементов 3 и 4 (3 + 4 = 7).

### Способ 1 (вложенные циклы):

| i | j | arr[i] + arr[j] | == k? |
|---|---|-----------------|-------|
| 0 | 1 | 1 + 3 = 4 | нет |
| 0 | 2 | 1 + 4 = 5 | нет |
| 0 | 3 | 1 + 10 = 11 | нет |
| 1 | 2 | 3 + 4 = 7 | **да!** → `return (1, 2)` ✅ |
