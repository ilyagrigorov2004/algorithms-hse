# Group Anagrams

## Объяснение решения

Дан список слов. Нужно сгруппировать **анаграммы** вместе.

**Анаграммы** — слова с одинаковым набором букв, но в разном порядке.

**Идея:** если отсортировать буквы в слове — анаграммы дадут **одинаковый ключ**.

**Пример:**
- `"eat"` → sorted → `"aet"`
- `"tea"` → sorted → `"aet"`
- `"ate"` → sorted → `"aet"`

Все три дают ключ `"aet"` → попадают в одну группу.

**Алгоритм:**
1. Создаём словарь `d`.
2. Для каждого слова:
   - Вычисляем ключ: `''.join(sorted(word))`.
   - Если ключ есть в словаре — добавляем слово в группу.
   - Если нет — создаём новую группу `[word]`.
3. Возвращаем `list(d.values())` — список групп.

## Оценка сложности

| Параметр | Оценка | Почему |
|----------|--------|--------|
| Время | O(n × k log k) | n слов, каждое сортируем за k log k |
| Память | O(n × k) | Храним все слова в словаре |

**Где:**
- `n` — количество слов.
- `k` — средняя длина слова.

**Почему `k log k`:** сортировка слова из k букв.

## Визуализация работы

**Пример:** `["eat", "tea", "tan", "ate", "nat", "bat"]`

| Шаг | word | key | Словарь d | Действие |
|-----|------|-----|-----------|----------|
| 1 | eat | "aet" | {} | `d["aet"] = ["eat"]` |
| 2 | tea | "aet" | {"aet": ["eat"]} | `d["aet"].append("tea")` → `["eat", "tea"]` |
| 3 | tan | "ant" | {"aet": ["eat", "tea"]} | `d["ant"] = ["tan"]` |
| 4 | ate | "aet" | {"aet": [...], "ant": ["tan"]} | `d["aet"].append("ate")` → `["eat", "tea", "ate"]` |
| 5 | nat | "ant" | ... | `d["ant"].append("nat")` → `["tan", "nat"]` |
| 6 | bat | "abt" | ... | `d["abt"] = ["bat"]` |

**Результат:**
```python
{
  "aet": ["eat", "tea", "ate"],
  "ant": ["tan", "nat"],
  "abt": ["bat"]
}
