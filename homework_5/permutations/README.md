# Permutations (Генерация перестановок)

## 1. Объяснение решения

Задача требует вернуть все возможные перестановки массива уникальных чисел. Для решения используется алгоритм поиска с возвратом (Backtracking).

**Как это работает:**
1. Мы поддерживаем текущую перестановку `current` и результирующий список `result`.
2. На каждом шаге мы перебираем все числа из исходного массива `nums`.
3. Если числа ещё нет в `current`, мы добавляем его (делаем выбор).
4. Рекурсивно вызываем функцию для следующего шага.
5. После возврата из рекурсии мы удаляем число из `current` (отменяем выбор, backtracking), чтобы попробовать другие варианты.
6. Когда длина `current` равна длине `nums`, мы добавляем копию `current` в `result`.

Для визуализации стека вызовов используется декоратор `@tracer` из первой задачи.

## 2. Оценка сложности

- **Время**: `O(n * n!)`. Существует `n!` перестановок. Для каждой перестановки мы копируем массив из `n` элементов, что дает `O(n)`. Итого `O(n * n!)`.
- **Память**: `O(n)` для хранения текущей перестановки `current` и стека рекурсии (глубина `n`). Список результатов занимает `O(n * n!)` памяти для хранения всех перестановок.

## 3. Визуализация работы алгоритма

**Пример:** `nums = [1, 2]`

```text
-> generate_permutations([1, 2])
    -> generate_permutations([1, 2], [1], [])
        -> generate_permutations([1, 2], [1, 2], [])
        <- generate_permutations([1, 2], [1, 2], []) = [[1, 2]]
    <- generate_permutations([1, 2], [1], []) = [[1, 2]]
    -> generate_permutations([1, 2], [2], [[1, 2]])
        -> generate_permutations([1, 2], [2, 1], [[1, 2]])
        <- generate_permutations([1, 2], [2, 1], [[1, 2]]) = [[1, 2], [2, 1]]
    <- generate_permutations([1, 2], [2], [[1, 2]]) = [[1, 2], [2, 1]]
<- generate_permutations([1, 2]) = [[1, 2], [2, 1]]
