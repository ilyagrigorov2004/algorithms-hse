# Tracer (Декоратор для трассировки рекурсии)

## 1. Объяснение решения

Задача требует создать декоратор, который визуализирует стек вызовов рекурсивных функций. Декоратор `tracer` оборачивает функцию и перехватывает каждый её вызов.

**Как это работает:**
1. Для определения глубины рекурсии используется модуль `sys` и функция `sys._getframe()`. Мы проходим по стеку вызовов (кадрам) и считаем, сколько раз встречается функция-обертка `wrapper`. Это число равно текущей глубине рекурсии.
2. На основе глубины формируется отступ: `indent = "    " * depth`.
3. При входе в функцию выводится строка вида `-> func(args)`.
4. Вызывается оригинальная функция, сохраняется результат.
5. При выходе выводится строка вида `<- func(args) = result`, и результат возвращается.
6. Используется `functools.wraps` для сохранения имени и метаданных оригинальной функции.

## 2. Оценка сложности

- **Время**: `O(d)`, где `d` — глубина рекурсии. На каждом шаге мы проходим по стеку вызовов для подсчёта глубины.
- **Память**: `O(1)` дополнительной памяти (не считая самого стека рекурсии).

## 3. Визуализация работы алгоритма

**Пример:** Вызов функции `factorial(3)` с декоратором `@tracer`.

| Шаг | Глубина | Действие | Вывод в консоль |
|-----|---------|----------|-----------------|
| 1 | 0 | Вход в factorial(3) | `-> factorial(3)` |
| 2 | 1 | Вход в factorial(2) | `    -> factorial(2)` |
| 3 | 2 | Вход в factorial(1) | `        -> factorial(1)` |
| 4 | 2 | Возврат 1 | `        <- factorial(1) = 1` |
| 5 | 1 | Возврат 2 | `    <- factorial(2) = 2` |
| 6 | 0 | Возврат 6 | `<- factorial(3) = 6` |

## 4. Тесты

Полный набор тестов находится в файле `test_tracer.py`. Запуск: `pytest test_tracer.py -v`.

Тесты покрывают:
- Проверку наличия ключевых строк в выводе (вход, отступы, возврат).
- Корректность возвращаемого значения (декоратор не ломает функцию).
- Работу функции без аргументов.
- Работу функции с именованными аргументами (`kwargs`).
