# Balanced Binary Tree (Сбалансированное бинарное дерево)

## 1. Объяснение решения

Задача требует определить, является ли бинарное дерево сбалансированным по высоте. Дерево считается сбалансированным, если для **каждого** узла высоты его левого и правого поддеревьев отличаются не более чем на 1.

**Идея алгоритма:**
Мы используем рекурсивный обход в глубину (post-order). Для каждого узла мы хотим узнать две вещи: 
1. Его высоту (чтобы родитель мог проверить баланс).
2. Сбалансировано ли его поддерево.

Вместо того чтобы возвращать два значения, мы используем трюк: функция возвращает **высоту**, если поддерево сбалансировано, и **`-1`**, если найден дисбаланс. 

**Как связана идея с реализацией:**
- Рекурсивная функция `check(node)` вызывается для левого и правого потомка.
- Если любой из потомков вернул `-1`, мы сразу возвращаем `-1` наверх (экономия времени, нет смысла считать дальше).
- Если разница высот левого и правого поддеревьев больше 1, возвращаем `-1`.
- Если всё в порядке, возвращаем реальную высоту: `max(left_height, right_height) + 1`.
- В самом конце мы проверяем: если `check(root) != -1`, значит дерево сбалансировано (True).

Такой подход позволяет обойти дерево всего один раз (снизу вверх) и избежать повторных вычислений высот.

## 2. Оценка сложности

| Параметр | Оценка | Объяснение |
|----------|--------|------------|
| **Время** | `O(n)` | Мы используем оптимизированный подход, при котором каждый узел дерева посещается ровно один раз (`n` — количество узлов). |
| **Память** | `O(h)` | Дополнительная память требуется только для стека рекурсии. В худшем случае (вырожденное дерево) высота `h = n`, в сбалансированном `h = log n`. |

## 3. Визуализация работы алгоритма

### Пример 1: Сбалансированное дерево (результат True)

Дерево:
```text
       3
      / \
     9  20
       /  \
      15   7
```

**Пошаговая работа функции `check(node)`:**
*Обход идет снизу вверх (post-order).*

| Узел | Высота левого | Высота правого | Разница | Возвращаемое значение |
|------|---------------|----------------|---------|-----------------------|
| 9 | 0 (None) | 0 (None) | 0 | **1** (лист) |
| 15 | 0 (None) | 0 (None) | 0 | **1** (лист) |
| 7 | 0 (None) | 0 (None) | 0 | **1** (лист) |
| 20 | 1 (от 15) | 1 (от 7) | 0 | **2** |
| 3 (корень) | 1 (от 9) | 2 (от 20) | **1** | **3** |

**Результат:** `check(3)` вернул `3` (не `-1`). Дерево сбалансировано. -> `True` ✅

---

### Пример 2: Несбалансированное дерево (результат False)

Дерево:
```text
    1
   /
  2
 /
3
```
*Ошибка:* узел 1 имеет высоту левого поддерева 2 и правого 0. Разница 2 > 1.

**Пошаговая работа функции `check(node)`:**

| Узел | Высота левого | Высота правого | Разница | Возвращаемое значение |
|------|---------------|----------------|---------|-----------------------|
| 3 | 0 (None) | 0 (None) | 0 | **1** (лист) |
| 2 | 1 (от 3) | 0 (None) | 1 | **2** |
| 1 (корень) | 2 (от 2) | 0 (None) | **2** ( > 1) | **-1** (дисбаланс!) |

**Результат:** `check(1)` вернул `-1`. Дерево не сбалансировано. -> `False` ❌

---

### Пример 3: Дисбаланс глубоко в дереве (результат False)

Дерево:
```text
        1
       / \
      2   3
     /
    4
   /
  5
```

**Пошаговая работа функции `check(node)`:**

| Узел | Левая высота | Правая высота | Разница | Возвращаемое значение |
|------|--------------|---------------|---------|-----------------------|
| 5 | 0 | 0 | 0 | **1** |
| 4 | 1 | 0 | 1 | **2** |
| 3 | 0 | 0 | 0 | **1** |
| 2 | 2 (от 4) | 0 | **2** (> 1) | **-1** (дисбаланс!) |
| 1 | Получает -1 от левого | - | - | **-1** (проброс наверх) |

**Результат:** `check(1)` вернул `-1` (потому что левое поддерево оказалось несбалансированным). -> `False` ❌

## 4. Тесты

Полный набор тестов находится в файле `test_balanced_tree.py`. Запуск: `pytest test_balanced_tree.py -v`.

Тесты покрывают:
- Пустое дерево (True).
- Дерево из одного узла (True).
- Идеально сбалансированные деревья разных уровней (True).
- Деревья с разницей высот ровно 1 (граница нормы, True).
- Деревья с разницей высот 2 (False).
- Вырожденные деревья: только левые дети или только правые дети (False).
- Сложные деревья с дисбалансом глубоко в поддереве, а не в корне (False).
